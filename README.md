### Resources

`TCP/IP addressing`
A system for uniquely identifying devices on a network using IP addresses (IPv4 or IPv6). An IP address contains both a network portion and a host portion.

`Subnet masks`
A method used to divide an IP address into network and host components. The mask defines which bits belong to the network and which to the device.

`Default gateways`
The IP address of a router that a host uses to send traffic to external networks when no specific route is available.

`OSI layers`
A 7-layer conceptual model that standardizes network communication

`Routers`
Layer 3 (network layer) devices that forward packets between different networks based on IP addresses and routing tables.

`Switches`
Layer 2 (data link layer) devices that connect devices within the same local network and forward frames using MAC addresses.
